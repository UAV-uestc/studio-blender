插件服务器 API 总结

Skybrush Studio Server API

用于无人机表演设计操作的主要后端 API。默认基础 URL 为 http://localhost:5000/api/v1/。

GET queries/version
获取服务器版本 ➔

功能：获取后端服务器版本，用于兼容性检查。

POST operations/decompose
分解点集 ➔

功能：将一组点分解为多个组，确保最小安全距离。

POST operations/render
渲染表演数据 ➔

功能：将无人机表演数据渲染为特定格式（如 .skyc、.csv 或图表）。

POST operations/multi-render
批量渲染数据 ➔

功能：在单次请求中将表演数据渲染为多种格式。

POST operations/create-static-formation
生成静态编队 ➔

功能：从 SVG 源文件生成静态无人机编队。

POST operations/match-points
点位匹配 ➔

功能：匹配源点位和目标点位，以实现无碰撞的过渡。

POST operations/plan-landing
降落规划 ➔

功能：为一组无人机计算降落轨迹和时间。

POST operations/plan-smart-rth
智能返航规划 ➔

功能：为“智能返航”程序建议启动时间。

POST operations/plan-takeoff
起飞规划 ➔

功能：规划分层起飞序列，以尽量减少下洗气流和碰撞。

POST operations/plan-transition
过渡规划 ➔

功能：计算直线过渡的可行最短持续时间。

Skybrush Gateway API

用于云端许可证认证（请求签名）和实时进度报告。默认基础 URL 为 http://localhost:5001/api/v1/。

GET hwid
获取硬件ID ➔

功能：获取机器的唯一硬件ID，用于设备识别与授权。

POST sign
请求签名 ➔

功能：使用本地网关对 JSON 请求体进行签名，用于与云端的安全认证。

POST task
创建任务 ➔

功能：在网关中创建一个具有进度跟踪的新任务。

PUT {task_url}
更新任务 ➔

功能：更新正在运行的任务的进度百分比和状态。

DELETE {task_url}
删除任务 ➔

功能：删除或完成进度任务。

Skybrush Viewer API

用于与本地 Skybrush Viewer 实例通信，进行实时 3D 可视化。端点通过 SSDP 动态发现。

GET api/v1/ping
检查连接 ➔

功能：检查 Skybrush Viewer 实例是否正在运行并可访问。

POST api/v1/load
加载表演数据 ➔

功能：将 .skyc 表演数据发送至 Viewer 进行即时 3D 轨迹可视化。

其他服务与发现机制

UDP 239.255.255.250:1900
SSDP 发现 ➔

功能：通过 SSDP M-SEARCH 多播请求自动发现局域网中的 Skybrush Viewer 实例，实现免配置连接。

HTTPS account.skybrush.io
硬件注册 ➔

功能：打开系统默认浏览器，引导用户在 Skybrush 云端账户中注册当前机器的硬件 ID 进行授权绑定。

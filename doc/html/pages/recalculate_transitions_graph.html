内部执行详情 (Internal Details)

update_transition_constraint_properties()
  • find_transition_constraint_between()
    查找当前无人机与故事板条目之间是否已有过渡约束。
  • 检查目标标记 (Check Marker)
    如果 marker is None (无目标)，则删除无人机上的过渡约束并返回 None。
  • 创建或重命名约束
    如果约束不存在，则通过 create_transition_constraint_between() 创建。
    如果已存在，则调用 set_constraint_name_from_storyboard_entry() 同步最新名称。
  • 设置约束目标 (Set Target)
    • 如果 marker 是一个独立对象 (marker is obj)，直接将约束的目标设置为该对象。
    • 如果 marker 是网格上的顶点，找到或创建只包含该顶点的顶点组 (Vertex Group)，然后将约束目标设为网格对象，子目标 (subtarget) 设为顶点组。
calculate_departure_index_of_drone()
  • 快速通道 (Fast Path)
    如果提供了 previous_mapping，直接从映射中查找无人机在上一编队中的目标索引，若不存在则返回 0。
  • 初始编队处理 (First Formation)
    如果没有 previous_entry，表示这是第一场编队，无人机从地面起飞，直接返回其全局 drone_index。
  • 查找上一过渡约束 (Find Previous Constraint)
    调用 find_transition_constraint_between() 获取无人机绑定到上一编队的约束。若无约束，则安全降级。
  • 处理目标类型 (Handle Target Type)
    • 如果是顶点组 (Vertex Group)，通过名称提示或遍历网格中的顶点，找到约束绑定到的具体顶点。
    • 如果是独立对象 (Object)，直接获取该对象作为目标。
  • 返回最终起飞索引 (Return Departure Index)
    在上一编队的所有目标列表中查找上述确定目标的具体位置，将其作为无人机的交错起飞索引。
update_transition_constraint_influence()
  • 构造数据路径 (Construct Data Path)
    根据约束名称构造目标数据路径，例如 constraints["Transition"].influence。
  • 确保动画数据存在 (Ensure Animation Data Exists)
    调用 ensure_animation_data_exists_for_object(drone) 为无人机对象创建或获取 AnimData 及其对应的动作 (Action)，以支持关键帧插入。
  • 应用影响曲线 (Apply Influence Curve)
    调用 descriptor.apply(drone, key) 将影响曲线应用于数据路径。内部处理包括：
    • 初始帧与预备阶段 (Windup)： 确认场景起始帧的影响值为 0 (首场过渡则为 1.0 以防跳动)，并保持该值直至 windup_start_frame。
    • 过渡阶段 (Transition)： 在 start_frame 插入关键帧，将影响权重爬升至 1.0。
    • 结束状态 (End)： 如果定义了 end_frame，在其位置再插入 1.0 的关键帧以维持约束状态，等待被后续过渡覆盖。
    • 写入关键帧 (Write Keyframes)： 调用 set_keyframes() 提交最终影响曲线

关键帧写入详情 (Keyframes Writing)

可让你随时间对 Blender 对象的特定属性（例如位置、旋转或自定义属性）制作动画。
set_keyframes()
  • 解析目标路径 (Resolve Target Path)
    根据传入的 data_path（例如 constraints["Transition"].influence），通过 object.path_resolve() 找到目标属性和具体的属性名。
  • 清理旧关键帧 (Clear Range)
    如果指定了 clear_range，则调用 clear_keyframes() 删除该时间段内已有的旧关键帧，避免冲突。
  • 插入新关键帧 (Insert Keyframes)
    遍历 values 列表，通过 target.keyframe_insert(prop, frame=frame) 为每一帧写入影响权重（如 0.0 或 1.0）。
  • 更新 F-Curve (Update F-Curve)
    查找新生成的 F-Curve，并在必要时设置插值模式 (Interpolation)，确保过渡平滑。

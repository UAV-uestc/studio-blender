Formation Transition Architecture

Visualizing the mapping and core data structures for drone formation transitions.

Transition Mapping (5 Drones → 4 Targets)

The physical trajectories in 3D space between formations are linear lines, but the timing/speed of the movement along those lines can be non-linear.

Core Data Structures

# start_points

Evaluated from [object.matrix_world.translation for obj in objects] at the end frame of the previous_entry.

Represents the 5 source positions of the drones before the transition begins.

# markers_and_objects

Returned from get_markers_and_related_objects_from_formation(formation).

Indicates the 4 target points (crossmarks) required by the target formation.

# Mapping

Returned from calculate_mapping_for_transition_into_storyboard_entry.

Dictates which start point transitions to which target point, handling cases with unequal entity counts (e.g., matching 5 drones to 4 targets gracefully).

# Constraints & Curves

CopyLocationConstraint

Applies the calculated target movement translation securely to the drone objects within Blender space.

  • target: Object
  • subtarget: str

InfluenceCurveDescriptor

Defines the interpolation and easing curves, dictating the fluid acceleration and deceleration of the drones over the transition timeline.

  • scene_start_frame: int
  • windup_start_frame: int | None # drone departure frame
  • start_frame: int # drone arrival frame
  • end_frame: int | None # start frame of the next entry
  • windup_type: InfluenceCurveTransitionType
    • # LINEAR
    • # SMOOTH_FROM_LEFT
    • # SMOOTH_FROM_RIGHT
    • # SMOOTH

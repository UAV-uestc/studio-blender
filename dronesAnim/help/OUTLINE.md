# 帮助文档初稿

文档源码放在 docs/，操作截图放在 docs/images/ 的对应功能目录。各页已列出准备讲的内容，详细步骤由作者补充。

先写无人机附着、曲线生成 Mesh 和 MAT 导出，再补灯光和检查功能。图片建议按内容命名，如 curve-count-panel.png。

操作步骤使用当前界面的按钮名。Mesh 附着会处理当前场景全部网格，重复点击已有附着时会删除整组无人机，这两点需要讲清楚。

曲线生成结果是当前帧的静态 Mesh。多选曲线时，数量为合计顶点数。间距按弧长计算，开放曲线包含两端，取整后实际间距通常略大。距离过短和弯折区域的说明放在对应章节。

灯效按列表从上到下的优先级叠加。已知的删除灯效后关键帧错位问题列入故障排查，修复后更新说明。

使用独立 Python 环境安装 requirements.txt 后运行 build.py，生成 site/ 离线网页。更新 docs/ 或图片后需要重新构建，再打包插件。
